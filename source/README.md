# KOKO Design Lab

## Четвёртый концепт — Maison KOKO

2026-10-06: добавлен Maison KOKO по четырём предоставленным изображениям. Молочный фон, светлое дерево, песочные оттенки и оливковая лента; отдельная desktop и mobile композиция. Фото хранятся локально без изменения исходников. Использование интерьерных референсов не утверждает, что показанное пространство уже открыто, а логотипы партнёров на упаковке не объявляют действующую рекламную акцию.

Maison находится первым в переключателе и открывается по умолчанию на пустом URL и при неизвестном concept. Явные ссылки ?concept=electric, gloss, skin остаются рабочими. В GitHub Pages основная ссылка: https://alexfudpim-tech.github.io/KOKO/; явная ссылка нового дизайна: ?concept=maison.

KokonutUI SmoothTab теперь рассчитывает число колонок по items.length; сокращённые подписи вмещают четыре темы на телефоне, полные названия сохраняются в aria-label. По Ponytail каталог, корзина, избранное и профиль общие для всех четырёх тем.

## Отдельная мобильная витрина

Сверху доступен переключатель «Мобильная / Компьютерная / Авто». Ручной выбор имеет приоритет над размером экрана; режим записан в параметре `ui` ссылки, сохраняется при переходах между разделами и учитывает историю браузера. Корзина и избранное при переключении не сбрасываются. В автоматическом режиме применяется порог 700 px.

Открыть `?ui=mobile&concept=electric` (также gloss и skin). На экранах до 700 px включается автоматически. Это отдельная композиция: портретный campaign hero, круглая горизонтальная навигация категорий, прокручиваемая товарная полка, компактные промо и нижняя навигация из пяти разделов. Корзина, избранное и профиль используют прежние данные без дублирования состояния. Поддерживаются безопасные отступы телефона и reduced motion. KokonutUI SmoothTab сохранён для выбора концепта; по Ponytail использованы существующие компоненты без новых зависимостей.

Проверено 2026-10-05: production build и автоматический offline render 12 мобильных маршрутов (4 раздела × 3 концепта) проходят. Визуальная проверка мобильной страницы и реальные нажатия в браузере НЕ выполнены: сохранённая настройка браузерного доступа блокирует localhost. ComfyUI status снова завершился тайм-аутом; новые изображения не генерировались. Для генерации потребуется запущенный ComfyUI API по адресу http://127.0.0.1:8188.

## GitHub Pages

Подготовлен `.github/workflows/pages.yml`: сборка и проверки перед публикацией `dist`. В репозитории выбрать Settings → Pages → Source: GitHub Actions; загрузить проект в ветку main. Относительные пути изображений и Vite base `./` поддерживают сайт в подпапке репозитория. Мобильная ссылка после публикации: адрес Pages + `?ui=mobile`. Документация: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

Исходники и готовая сборка загружены в https://github.com/alexfudpim-tech/KOKO. В GitHub приложение хранится в source/, готовая витрина — в корне; workflow использует source/ как рабочую директорию. Загрузка кода не подтверждает доступность Pages: статус публикации необходимо проверять отдельно. Для передачи исходников использовать проверенный экспорт `scripts/export-github.ps1`: он исключает историю Git, служебные данные Sites, кэш, локальные отчёты и секреты. Пароли/токены не передавать в чат.

Четыре интерактивные витрины. Действующий магазин не изменён.

- **Maison KOKO** — cream/oak/olive, фото-референсы пространства KOKO, Prata и спокойная торговая композиция; открывается по умолчанию.
- **Electric Market** — cobalt/lime, крупная fashion-типографика, динамичная торговая композиция.
- **Gloss Atelier** — blush/burgundy, Prata, журнальная beauty-композиция.
- **Skin Archive** — teal/water, спокойная типографика, уход и составы.

Переключатель сверху меняет полный визуальный мир. Работают поиск, категории, сортировка, карточка товара, избранное и тестовая корзина. Кнопка выбора сохраняет предпочтение только в этом браузере. Корзина и избранное также локальные. Демо не принимает заказы, платежи или персональные данные. Цены не являются подтверждённым прайсом KOKO.

## Запуск

Node 22.12+; npm install, npm run dev. Локальная витрина: http://127.0.0.1:3006/. npm run build создаёт dist, npm run check проверяет фильтры, суммы, локальные изображения и сохранение дизайн-контракта в сборке.

Ссылки концептов: ?concept=electric, ?concept=gloss, ?concept=skin. Каталог: &view=catalog.

Обновление 2026-10-05: добавлены Beauty Week, два рекламных product-edit блока и приглашение в профиль. Пример −15% и BEAUTY15 не действуют и не изменяют цены. Профиль &view=profile содержит три раздела: обзор, избранное и настройки превью ухода. Настоящего входа, аккаунта и истории покупок нет. Сохраняются только настройки интерфейса на устройстве; персональные данные не запрашиваются. Использован тот же адаптированный KokonutUI SmoothTab с отдельными ARIA IDs. ComfyUI status завершился тайм-аутом, поэтому новой генерации нет.
